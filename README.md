# Eduardo Carvalho Portfolio

## Open locally

Open `index.html` in a browser. All images, video and the CV are stored in `assets/`.

## Make content changes

- Main text, sections, colours and layout: edit `index.html`.
- PHISEC images/video: `assets/phisec/`.
- F1 in Schools images: `assets/alpha-scorpii/`.
- CV download link: replace `assets/Eduardo_Carvalho_CV.pdf` with a newer PDF using the same file name.

## Before publishing

Confirm with PHISEC Racing that the car render, team photo and CFD video are approved for public use. The site deliberately does not publish detailed CFD settings, coefficients, geometry or performance data.

## Publish with GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload this folder's contents — `index.html` must be at the repository root.
3. In GitHub, open **Settings → Pages** and publish from the main branch/root.
4. The site will be available at `https://<your-github-username>.github.io`.

Use the public site link in future applications only after checking every image, video and link on a phone and desktop browser.
